Proposed Solution· 02

The document is the event; the clock is the section.

  • Digitises the full lifecycle — proposal → SIA → notification → objections → declaration → award → compensation → possession → R&R — under RFCTLARR 2013 and the Fourth Schedule acts as configurable rule-sets.
  • Documents are the events: officers upload the gazette, award or payment; the system extracts the fields, the officer confirms, the ledger commits.
  • Statutory clocks are first-class objects with alerts and consequences s.19(7) s.25 s.38 s.30(3).
  • National → state → district → project dashboards computed from the ledger, so every figure traces to a document.
  • Beyond Bhoomi Rashi: all statutes, all requiring bodies, plus family-level R&R and a hash-chained ledger it does not have.

Stack — mirrors the PS's suggested tooling

  • PostgreSQL + PostGIS · Leaflet · REST (OpenAPI 3.1)
  • FastAPI (Python) · React + TypeScript · MinIO documents
  • LLM field extraction with regex fallback for gazette formats
  • Docker · MeghRaj-deployable · Keycloak-compatible JWT/RBAC

Methodology

  • Rule-sets as versioned YAML: stages, clocks, extensions, consequences — per statute and state
  • Event ledger → projections → dashboards; nightly clock evaluation + escalation
  • Adapters (mock, honest): ULPIN · PFMS · e-Gazette · DigiLocker · Gati Shakti

Feasibility & Viability· 04

Public rules. Public data. NIC-hostable stack.

  • Rules are public — the Act and the 2014 Rules; data is public — e-Gazette notifications and Bhoomi Rashi project pages.
  • Working prototype: one real NH project walked from the 3A notification to award, clocks running, audit trail intact.
  • Stack is open source and already what NIC hosts on MeghRaj.

Impact & Benefits· 05
  • Time — digitising NH acquisition raised notifications from ~1,000/yr to 2,842 in year one; BhuArjan extends that to every statute and sector.
  • Money — every month of delayed compensation accrues 12% · s.30(3); a missed s.25 deadline restarts acquisition from zero. Clocks with escalation stop both.
  • Transparency — family-level R&R visible to the Commissioner and Ministry; public parcel status for citizens.
  • Governance — a national real-time view replacing quarterly paper returns.
  • Social — entitlements tracked to delivery; SC/ST and Scheduled-Area provisions ss.41–42 modelled explicitly.
