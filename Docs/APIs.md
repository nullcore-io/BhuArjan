# APIs.md — REST /v1 (OpenAPI 3.1)

Base URL `/api/v1`. JSON everywhere except document upload (multipart) and GeoJSON endpoints (`application/geo+json`). All timestamps ISO-8601; legal dates as `YYYY-MM-DD`. Money as integer paise. Areas as hectares (`numeric` string). The full OpenAPI document is generated by FastAPI at `/api/v1/openapi.json`; this file is the human contract.

---

## 1. Conventions

| Concern | Rule |
|---|---|
| Auth | `Authorization: Bearer <JWT>`; claims: `sub`, `roles[]`, `scopes[]` (org-unit ids), `exp` |
| Jurisdiction | Enforced server-side on every read/write; out-of-scope → `404` (not `403`, to avoid enumeration) |
| Idempotency | `Idempotency-Key` header required on `POST /cases/{id}/events` and `POST /documents`; replay returns the original `201` |
| Concurrency | `If-Match: <case_state.as_of_seq>` optional on event append; mismatch → `409` |
| Pagination | Cursor: `?limit=50&cursor=<opaque>`; response `next_cursor` |
| Errors | RFC 7807 `application/problem+json`: `type`, `title`, `status`, `detail`, `instance`, `errors[]` (field-level), `ruleset_ref` (when a rule rejected) |
| Versioning | Path `/v1`; breaking changes → `/v2` |
| Demo clock | `X-Demo-Date: 2026-11-30` honoured only when `DEMO_MODE=true` |
| Rate limits | Public endpoints 60 req/min/IP; authenticated 600 req/min/user |

### 3.4 Event append — the core write

Request:
```http
POST /api/v1/cases/7f3c.../events
Idempotency-Key: 2c4f0d7e-...
If-Match: 418
Content-Type: application/json

{
  "type": "DECLARATION_S19",
  "occurred_at": "2026-03-14",
  "document_id": "d8a1...",
  "payload": {
    "gazette_no": "S.O. 1234(E)",
    "villages": [{"lgd": "123456", "survey_nos": ["123/1","124"], "area_ha": "3.4120"}],
    "rr_scheme_summary_ref": "d7b2...",
    "confirmed_fields": ["gazette_no","villages"],
    "corrected_fields": ["villages[0].area_ha"]
  }
}
```
Response `201`:
```json
{ "seq": 419, "id": "e91...", "hash": "9f2c...", "prev_hash": "b7a1...",
  "stage": "DECLARED",
  "clocks_changed": [
    {"clock_id":"DECLARATION_S19","status":"closed","closed_on":"2026-03-14"},
    {"clock_id":"AWARD_S23","status":"running","start_date":"2026-03-14","due_date":"2027-03-14","basis":"s.25"}
  ]}
```
Rejections (`422`, problem+json):
- `transition_not_allowed` — `ruleset_ref: "RFCTLARR_2013@2026.09/transitions/DECLARATION_S19"`, `detail: "current stage APPRAISED; DECLARATION_S19 allowed from NOTIFIED"`.
- `precondition_failed` — `errors: [{"missing":"COST_DEPOSITED_S19_2","section":"s.19(2)"}]`.
- `guard_failed` — possession before full payment, with `comp_paid`, `comp_assessed`.
- `document_required` — statutory event without `document_id` and without `no_document_reason` by a permitted role.

Special payloads:
- `EXTENSION_GRANTED`: `{clock_id, authority, order_ref, reasons, new_due_date}` — document required.
- `COURT_STAY` / `STAY_VACATED`: `{court, case_no, order_date, affected_clocks[]}`.
- `PAYMENT_MADE`: `{pfms_ref, amount_paise, payee_ref, mode}`.
- `EVENT_REVERSED`: `{reversed_event_id, reason}` — Collector or above.

## 4. Integration adapters (interfaces; mock implementations in the prototype)

| Adapter | Interface | Real target | Mock behaviour |
|---|---|---|---|
| `ulpin` | `lookup(ulpin) → {owner_ref_masked, area_ha, village_lgd, record_url}`; `by_survey(state, district, village, survey_no)` | State Bhulekh / DILRMP APIs via ULPIN | Fixture table for seeded villages |
| `pfms` | `payment_status(pfms_ref) → {status, amount, date}`; `list_payments(case_ref)` | PFMS APIs | Fixture statuses; `PAID` after 2 min in demo |
| `gazette` | `search(statute, section, from, to, state) → [notification refs]`; `fetch(ref) → pdf` | egazette.gov.in | Local cache of scraped PDFs |
| `digilocker` | `issue(document_id) → uri`; `esign(document_id, signer) → signed pdf` | DigiLocker / eSign (CDAC) | Stamps a watermark |
| `gatishakti` | `export(project_id) → GeoJSON/WMS layer` | PM Gati Shakti NMP | Writes GeoJSON to MinIO with a public URL |
| `notify` | `send(channel, to, template, vars)` | DLT-registered SMS, SMTP, push | Console + in-app |

Adapters are selected by config; `GET /admin/integrations` shows `mock` vs `live` truthfully — say so on stage.

## 5. Webhooks (outbound)

Subscribers (e.g. a requiring body's system) register `POST /webhooks {url, events[], secret}`. Payload: `{event_id, case_id, type, occurred_at, seq, hash}` signed with HMAC-SHA256 in `X-Signature`. Retries with backoff; dead-letter after 24 h.

## 6. Error catalogue

| `type` | HTTP | When |
|---|---|---|
| `validation_error` | 422 | Schema/field errors |
| `transition_not_allowed` | 422 | Event not permitted from current stage |
| `precondition_failed` | 422 | Missing required prior event |
| `guard_failed` | 422 | Rule guard false (e.g. possession before payment) |
| `document_required` | 422 | Statutory event without document |
| `stale_state` | 409 | `If-Match` mismatch |
| `duplicate_request` | 200/201 | Idempotent replay |
| `not_found` | 404 | Missing or out of jurisdiction |
| `unauthenticated` | 401 | — |
| `rate_limited` | 429 | — |
| `integrity_violation` | 500 | Hash chain mismatch detected on write |

## 7. OpenAPI excerpt (event append)

```yaml
paths:
  /cases/{caseId}/events:
    post:
      summary: Append a statutory or operational event to the case ledger
      parameters:
        - in: header
          name: Idempotency-Key
          required: true
          schema: { type: string, format: uuid }
        - in: header
          name: If-Match
          schema: { type: integer }
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required: [type, occurred_at, payload]
              properties:
                type: { $ref: '#/components/schemas/EventType' }
                occurred_at: { type: string, format: date }
                document_id: { type: string, format: uuid }
                no_document_reason: { type: string }
                payload: { type: object }
      responses:
        '201': { $ref: '#/components/responses/EventAppended' }
        '409': { $ref: '#/components/responses/Problem' }
        '422': { $ref: '#/components/responses/Problem' }
```
